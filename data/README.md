# data — Datasets & Images

This folder stores downloaded images and dataset files.

> ⚠️ This folder is listed in `.gitignore` — its contents are NEVER uploaded to GitHub.
> This protects you from accidentally sharing large files or licensed data.

Subfolders will be created here in later stages, for example:
- `raw/` — original downloaded images
- `processed/` — resized or cleaned images ready for training
